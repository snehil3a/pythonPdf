## PDF Merger Tool

This Python script merges all PDF files in a specific directory into a single PDF file.

### Features
- Automatically detects all PDF files in the specified directory
- Merges them into a single combined PDF
- Simple and easy to use

### Usage
1. Place all your PDF files in the target directory
2. Run the script
3. Find the merged PDF in the output location

### Requirements
- Python 3.x
- PyPDF2 library
